02 Single ALU: 1-Trit Ternary Adder

Wavelength Encoding
Red 1.550 μm = -1
Green 1.216 μm = 0
Blue 1.000 μm = +1
  A (R/G/B) ──┐
               ├──▶ [ SFG Mixer ] ──▶ [ 5-Ch AWG DeMux ] ──┬── DET₋₂ (0.775 μm) BORROW
  B (R/G/B) ──┘       χ² LiNbO₃       separates output λ   ├── DET₋₁ (0.681 μm) Result: -1
                                                          ├── DET₀  (0.608 μm) Result:  0
                      f_out = f_A + f_B                   ├── DET₊₁ (0.549 μm) Result: +1
                      (sum-frequency)                     └── DET₊₂ (0.500 μm) CARRY

Key insight: Green = harmonic mean of Red and Blue

λ_Green = 2 × λ_Red × λ_Blue / (λ_Red + λ_Blue) = 1.216 μm → ensures R+B and G+G both produce 0.608 μm (verified by Meep FDTD)

03 81-Trit Carry Chain

  LSB                                                                    MSB
  ┌───────┐    ┌───────┐    ┌───────┐          ┌───────┐    ┌───────┐
  │ ALU 0 │───▶│ ALU 1 │───▶│ ALU 2 │── ··· ──▶│ALU 79 │───▶│ALU 80 │
  │       │carry│       │carry│       │   carry  │       │carry│       │
  └───┬───┘    └───┬───┘    └───┬───┘          └───┬───┘    └───┬───┘
      │            │            │                   │            │
    digit₀       digit₁       digit₂            digit₇₉      digit₈₀

  CARRY LOGIC (each trit position):

  sum = A[i] + B[i] + carry_in

  ┌────────────────────────────────────────────────────┐
  │  if sum ≥ +2 :  digit = sum - 3,  carry_out = +1  │
  │  if sum ≤ -2 :  digit = sum + 3,  carry_out = -1  │
  │  otherwise   :  digit = sum,      carry_out =  0  │
  └────────────────────────────────────────────────────┘

  Hardware: DET₊₂ fires → carry = +1,  DET₋₂ fires → carry = -1
  Total propagation: ~1.6 ns across 81 trits at 617 MHz clock
